# v0.2.0 Beta Release Notes

> 发布状态：`blocked`。仅在 [匿名真实试跑协议](beta-pilot-protocol.md) 完成、脱敏报告经人工审阅且 GitHub CI 通过后，才可将本文件用于 GitHub `v0.2.0` pre-release。

## 包含内容

- MIT 授权的本地证据优先科研工作流。
- 175 个已安装 Skill、严格 Catalog/目录/旧 ID 映射检查，以及逐项验证矩阵。
- 本地项目契约、时间线状态闸门、原始数据仅登记规则、私有试跑审计器，以及受控 MCP 写入关卡与收据链。

## 已验证

- GitHub CI 将在 Python 3.11 与 3.12 上运行 pytest、插件校验、Catalog/验证映射/写入策略报告、隔离运行时初始化及 MCP 工具发现 smoke test。
- 结构检查与确定性契约检查的边界见 [验证模型](verification-model.md)。

## 尚未验证或不支持

- 在实际脱敏试跑报告填入前，不得声称端到端真实试跑完成。
- 不联网核验来源或期刊；不读原始敏感数据；不提交、上传或登录外部系统。
- 不保证 LLM 输出质量、研究结论、来源真实性、投稿合规或投稿结果。
