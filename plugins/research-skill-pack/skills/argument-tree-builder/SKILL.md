# Argument Tree Builder

将中心论点和已核验论证单元组织为可检查的树；节点必须指向已存在 artifact。

## 前置与输出

- 输入为 Central Thesis、Argument Unit、Research Question 与限制。
- 输出 `argument_tree` artifact，显示父子主张、支撑证据、反例、章节归属和缺口。
- 不允许孤立核心节点；缺口必须显式保留，不以语言填补。
