# Citation Diversity Auditor

识别引用证据集中风险，保留其真实研究原因而不为了平衡乱引。

## 前置与输出

- 输入为已核验 Citation Usage 与 Source metadata。
- 输出 `citation_diversity_report`，说明集中位置、潜在盲点和需人工核验项。
- 不将“多样”当作来源可信或论文质量的替代指标。
