# Discussion Writer

按“发现→解释→文献比较→意义→限制”组织讨论，区分结果本身与解释。

## 前置与输出

- 输入为 Results、Conflict Map、限制清单和 Paragraph Blueprint。
- 输出 `manuscript_section`，每层标记 Evidence/Interpretation/Comparison/Implication。
- 不夸大因果或普遍性，不隐去反例、失败结果和设计限制。
