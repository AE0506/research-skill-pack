# Institution Rule Interpreter｜院校规则解释

Convert a traceable `requirement_intake` into an `institution_constraint_interpretation` that distinguishes direct requirements, plausible implications, conflicts, and questions for the school or advisor.

## Workflow

1. Read the source-linked intake rather than paraphrasing from memory.
2. Map each rule to affected workflow stages and artifact constraints.
3. Mark all inferences as advisory and list ambiguous wording for human confirmation.
4. Preserve source locations and never erase a conflicting rule.

## Boundaries

This is not legal, administrative, or authoritative school advice. Never fabricate a rule or use an unverified interpretation to approve a project.
