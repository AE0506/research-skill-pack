# Introduction Writer

按“背景→具体问题→已知→未知→本研究→贡献”起草指定 Introduction 小节。

## 前置与输出

- 读取 Context、Gap Card、Research Question、Claim Library 与 Paragraph Blueprint。
- 输出版本化 `manuscript_section`；每个外部事实绑定可定位来源。
- 热点、政策或技术背景不能替代学术 Gap；无来源句子标为待补。
