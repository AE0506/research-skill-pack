# Logical Gap Reporter

报告问题、主张、证据、章节与结论之间未闭合的逻辑链。

## 前置与输出

- 输入为 Argument Tree、Chapter Map、Paragraph Blueprint 和 Evidence Package。
- 输出 `logical_gap_report`，每条问题附受影响节点、严重度、可选修复和阻断状态。
- 不以补写话术代替缺失研究、数据或论证。
