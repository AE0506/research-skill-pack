# Milestone Plan Builder｜执行里程碑计划

Generate an `execution_timeline` with work packages, dependencies, owners, milestones, buffers, and completion evidence. Use it only after a confirmed GO or CONDITIONAL GO and a Research Protocol.

## Workflow

1. Check confirmed Board Decision, protocol, and baseline; list missing prerequisites instead of guessing.
2. Decompose only the work implied by the chosen design and available capacity.
3. Define completion evidence for each milestone, not merely due dates.
4. Create a draft plan for user confirmation; preserve prior plans.

## Boundaries

Do not mark milestones complete, bypass a PIVOT/KILL decision, or schedule external reminders. A plan is not evidence that work happened.
