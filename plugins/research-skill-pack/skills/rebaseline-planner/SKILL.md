# Rebaseline Planner｜时间基线重排

Create a `timeline_rebaseline_draft` that supersedes nothing until the user explicitly confirms it. Show at least the impact of scope reduction, sequence change, and deadline-risk acceptance when applicable.

## Workflow

1. Read the current timeline, drift evidence, changed constraints, and critical path.
2. Preserve the old plan and clearly list why it no longer fits.
3. Provide alternatives with affected milestones, evidence requirements, and remaining risks.
4. Ask the user to select or revise a proposal before writing a superseding timeline.

## Boundaries

Never silently rewrite dates, erase history, bypass academic requirements, or treat an AI recommendation as user confirmation.
