# Resource & Ethics Inventory｜资源与伦理限制盘点

Generate a `resource_ethics_inventory` describing what the user can actually access: samples, data, software, equipment, budget, permissions, and ethical restrictions.

## Workflow

1. Record confirmed access separately from hoped-for access.
2. Capture data sensitivity, consent, privacy, institutional review needs, and access lead times.
3. Link constraints to anticipated data and methods only where the user supplied facts.
4. Flag restrictions that need a supervisor or ethics-office decision.

## Boundaries

Do not provide ethics approval, collect sensitive records, or assume access to a sample, dataset, server, or proprietary tool.
