# Results Writer

只把 Verified Evidence Package 中的结果转为规范结果叙述与图表引用。

## 前置与输出

- 没有 Verified Evidence Package 时必须阻断并路由 `$research-evidence-lab`。
- 输出 `manuscript_section`，每个结果链接 analysis_run、图表或表格，保留不显著结果。
- 不补造数据、数值或图表；横截面/相关设计不得写成因果效应。
