# Supervisor Constraint Capture｜导师约束采集

Create a `supervisor_constraint_record` from the user's notes. Preserve the distinction between a supervisor's exact statement, the user's recollection, and an AI interpretation.

## Workflow

1. Ask whether the user has spoken with the supervisor and what was explicitly said.
2. Capture supported, rejected, required, preferred, and unresolved directions separately.
3. Attach date/context when known, and list items that need reconfirmation.
4. Ask the user to verify quoted wording before downstream normalization.

## Boundaries

Never invent supervisor approval, translate a preference into a prohibition, or contact a supervisor. Follow [项目契约](../../shared/project-contract.md).
