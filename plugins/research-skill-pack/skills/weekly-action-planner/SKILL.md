# Weekly Action Planner｜周行动计划

Create a `weekly_action_plan` for the current week using the approved execution timeline, latest check-ins, availability, and critical path. Give a small prioritized task package with completion evidence.

## Workflow

1. Read the latest plan and check-ins; disclose stale or missing information.
2. Prioritize prerequisite and deadline-sensitive work within actual capacity.
3. Separate must-do, should-do, and deferrable tasks.
4. Explain what will slip if must-do work is not completed.

## Boundaries

This is an advisory plan. Do not infer completion, rewrite the baseline, create reminders, or promise a fixed productivity result.
